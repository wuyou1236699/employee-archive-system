# 自有环境部署边界

默认开发、构建预览均离线。本候选没有部署脚本、真实配置或云端初始化数据。VITE_ENABLE_CLOUDBASE 必须显式设为 true 才允许前端初始化 SDK；浏览器公开配置与服务端管理凭据必须分离。

后端业务入口为 index.main，目标 Node.js 18.15，SDK 固定 3.18.3。安装锁定依赖后仍须核对实际解析版本。只将 index.js、package.json、npm-shrinkwrap.json 和核验后的依赖纳入业务部署包；排除测试、夹具、文档、环境文件和日志。

代码中的集合名称是接口契约，不表示任何集合已创建。虚构 storage authority 只能用于本地测试，真实部署须配置自己的精确环境映射，禁止通过放宽附件路径权限规避配置。

员工文档采用嵌套 contract/vehicle；旧合同读取、旧客户端提交和显式 null 优先级以源码为准。这里不包含自动迁移工具，也不宣称支持未知历史结构。展示季度维度和评分文案专为演示重写，不能与某个已有业务数据库直接混用。

需要上线到自己的隔离环境时，应独立验证认证、权限、索引、附件存储、真实文档持久化与事务回滚。静态页面部署应使用独立网站，回退仅恢复代码与静态文件，不回退数据库、不删除附件。源码存在、构建通过或函数可调用都不等于业务验收通过。
