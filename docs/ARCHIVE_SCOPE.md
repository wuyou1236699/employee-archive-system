从已准备的 78 文件脱敏候选的当前暂存树选取内容，没有复制 .git、node_modules、构建目录或隐藏环境配置。原正式版本的后端发布入口与前端项目模块在前序工作中已经核对；本轮没有操作正式云端。

公开候选共 81 个源码、测试、配置和文档文件。新增离线模式开关、6 项连接边界测试和开发历程文档。完整演示员工档案重新生成；季度维度、标准全文和组织术语改为虚构通用示例。展示专用修改不回写正式项目或私有候选。

后端忽略字符串字面值、并还原展示维度名称后的非字符串代码 token 与已验收入口一致；附件、合同、车辆处理逻辑没有重新实现。5 份前后端依赖声明及锁文件字节不变。已选取的 71 个正式源文件与本轮开始前保留的内容一致。

## 脱敏与历史

候选源码、测试、配置、文档、注释和构建文件已扫描已知真实环境及地址、历史真实附件标识、原样例敏感值、凭据模式、内部组织词语及本机路径。未发现上述残留。所有硬编码手机格式输入位于合成演示号段；测试 UID、环境映射和存储键均为虚构契约输入。

未复制真实图片、附件、表格、数据库快照或内部日志。源码树和构建目录无图片及媒体文件，因此不存在这些文件的 EXIF 或 Office 元数据。锁文件保留公共依赖下载与赞助地址；它们不是原系统生产地址。

新 Git 仓库只包含本次整理快照，不继承任何旧提交、reflog 或远端配置，不伪造过去日期。构建、依赖安装目录与本地配置被忽略，不属于拟公开内容。

默认运行只使用内存演示；刷新即重置。不携带可执行正式部署配置，不执行云端隔离服务，不连接正式数据库。源码中的通用权限、字段及集合名称保留为工程契约。

## 项目性质和未覆盖边界

本项目为作者在职期间为所在单位开发的内部业务系统，本仓库为移除真实数据、账号与环境配置后的技术展示版本。

本轮未进行浏览器设备兼容性、真实认证/存储/事务或新环境部署验收。全库测试与 lint 不全绿的问题已公开说明。安全扫描覆盖当前可识别的敏感模式及已知源值，不把自动扫描描述为对所有未知信息的绝对保证。
